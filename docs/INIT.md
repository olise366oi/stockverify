# 初始账号

本地数据库内置以下初始账号（用户名 + 密码），用于功能核验与演示。首次登录后建议在「设置 → 修改密码」中更换。

> 说明：密码以 bcrypt 哈希存储于 `users.password_hash`，数据库不落明文。生产环境请部署后立即修改这些初始密码。

| 身份 | 用户名 | 初始密码 |
|---|---|---|
| 总部管理端（超管，可管理商品库与财务设置） | `admin_01` | `Admin@2024` |

## 登录入口

- 合作商铺：`http://localhost:3000`（用户名 + 密码）
- 品牌方 / 管理端：`http://localhost:3000/register.html`（选择品牌 / 管理身份后登录）

## 账号管理

- 新开商铺 / 品牌 / 管理端账号由超管在管理端开通，开通时生成的密钥即该账号的**初始登录密码**；
- 修改密码：商铺端「设置 → 修改密码」（非超管仅可修改一次）；管理端「修改密码」；
- 超管可在「管理端账户」列表重置管理端密码。
